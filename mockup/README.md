# VDA Telkonet — Smart Room Control Mockup

Wall-mounted all-in-one device UI built with React + Tailwind CSS + Motion.

## Features

- **Boot screen** — animated splash with VDA Telkonet and FindMe logos, loading bar
- **Control panel** — live clock, temperature control, lighting with brightness presets, HVAC fan speed, system status
- **Occupancy fullscreen** — tap the occupancy banner to expand a full-screen FindMe True Presence Detection view (OCCUPIED / VACANT)
- **Wall mount scene** — device rendered as a physical bezel on a plaster wall background

## Stack

- React 18 + TypeScript
- Tailwind CSS v4
- Motion (Framer Motion)
- Lucide React icons
- Google Fonts: Inter + JetBrains Mono

## Assets

Place your logo files in `src/imports/`:
- `logoFindME.png` — FindMe solution logo
- `meng.png` — VDA Telkonet company logo

## Run

```bash
npm install
npm run dev
```
